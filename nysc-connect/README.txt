NYSC CONNECT PROJECT
====================

All pages and CSS files are contained in this single nysc-connect folder.

Main pages:
- index.html              Home
- signup.html             Create account
- verify-email.html       Email verification
- verify-sms.html         SMS verification
- login.html              Login
- forgot.html             Forgot password
- check-email.html        Email reset message
- check-sms.html          SMS reset message
- newpass.html            Set new password
- profile.html            Profile setup

The project uses relative local links, so it can be opened from the folder or uploaded to a web server.
External images in the original designs are preserved.
